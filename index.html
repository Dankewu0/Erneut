Erneut is a clean single-page landing that showcases essential front-end technologies. It uses a responsive design and an interactive slider to present tools like SCSS, HTML, JavaScript, and Swiper. The page serves as a quick overview of a modern web development stack.

Technologies Used

SCSS is an extended version of CSS that adds variables, nested styles, functions, and mixins to interface development. It is fully compatible with regular CSS but makes writing code much faster, cleaner, and easier to maintain. All SCSS code is automatically compiled into a standard CSS file that web browsers can read without any issues.

HTML (HyperText Markup Language) is the standard markup language used to create the structure and skeleton of web pages. It consists of tags that tell the browser where headings, lists, images, links, and plain text are located on the page. HTML is solely responsible for the skeleton and content of the site, while the appearance (styles) is configured using CSS.

JavaScript (JS) is a multi-paradigm programming language that brings web pages to life by making them interactive. It runs directly in the browser and handles logic: processing clicks, submitting forms without reloading, animations, working with APIs, and updating content on the fly. Together with HTML (skeleton) and CSS (appearance), JavaScript is the third fundamental component of front-end development.

Swiper is the most popular and modern JavaScript plugin for creating responsive touch sliders on websites and mobile apps. It works without third-party libraries (like jQuery) and has built-in support for gestures, swipes, smooth acceleration, and 3D effects. Swiper easily integrates with all popular frameworks (Vue, React, Angular) and is used on millions of websites to create carousels, galleries, and responsive blocks.
